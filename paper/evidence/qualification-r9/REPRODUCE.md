# Reproducing edition 9

The deployed runtime is `8ba7ab7040da0522a02ea0c222801e2a072efa05`. Start with `sources/source-8ba7ab7040.tar.gz` in the ZIP, or check out that commit. Its root, client and hosted npm lockfiles, Rust provider, bundled OpenMLS artifacts, TLC source and model runner are included. The archive excludes only the earlier paper subtree. The supplemental harness files under `reproduction/` can be copied over the corresponding paths **in a new source directory** to run this edition’s supplemental all-decline, backpressure and hosted lifetime probes; they do not change the implementation. The evidence tag already contains them.

`qualification.json` lists commands and exclusions. `models.json` distinguishes successful safe searches from counterexamples that were required. `models/` in the ZIP contains the exact TLC configurations, modules and transcripts; only local file-path prefixes in the transcripts are abbreviated. `fault-schedules.json` separates observed socket closure from a censored silent-network observation. `participant-journeys.json` records independent receiver assertions. `deployment.json` identifies both production versions, matches the web bundle bytes and reports the normal production room checks. The artifacts do not contain room invitations, grants, private messages or participant credentials.

Use an unused local output directory. Run the loopback scenarios before considering live cases. Production checks require separate authorization, only self-owned rooms, spare service capacity and session cleanup. Never run a fault-injection or load scenario on the public service.
